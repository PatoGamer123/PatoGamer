# Bloqueo de apps 1.0 Release

Modo de presentación para ventanas abiertas de Windows. Maximiza y fija una ventana en primer plano. No es un quiosco de seguridad: otras aplicaciones, pestañas y atajos siguen disponibles. Cualquier persona puede soltar la ventana desde el panel.

[Descargar para Windows](https://raw.githubusercontent.com/PatoGamer123/PatoGamer/main/bloqueo-de-apps/Bloqueo-de-apps-1.0.zip) · [Mando opcional para Android](https://raw.githubusercontent.com/PatoGamer123/PatoGamer/main/bloqueo-de-apps/Bloqueo-Mando.apk)

Extrae el ZIP, abre BloqueoDeApps.exe y elige una ventana abierta. Para usar el teléfono, activa el mando y copia la dirección y clave en Android dentro de la misma red.
