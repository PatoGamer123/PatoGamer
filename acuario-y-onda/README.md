# Acuario Studio y Onda LAN

| Descarga | Cómo usarla |
|---|---|
| [Acuario Studio 1.1 para Windows](https://raw.githubusercontent.com/PatoGamer123/PatoGamer/main/acuario-y-onda/descargas/Acuario%20Studio%201.1%20Release.zip) | Extrae el ZIP y abre AcuarioStudio.exe desde su carpeta definitiva. Inicia con cuatro peces a 60 FPS. |
| [Onda LAN 1.0 para Windows x64](https://github.com/PatoGamer123/PatoGamer/releases/download/onda-lan-1.0/OndaLAN-Windows-x64.zip) | Extrae la carpeta completa y abre OndaLAN.exe. |
| [Onda LAN 1.0 para Android](https://raw.githubusercontent.com/PatoGamer123/PatoGamer/main/acuario-y-onda/descargas/OndaLAN-Android.apk) | Abre el APK en Android 6 o posterior para instalarlo. |

En iPhone, TV o VR con navegador, abre el enlace de una sala Onda LAN creada en la misma red. La disponibilidad de carga y descarga depende del navegador.
