# Acuario Studio y Onda LAN

## Acuario Studio 1.1 para Windows
Extrae el ZIP de descargas y ejecuta AcuarioStudio.exe desde su ubicación definitiva. Se abre al iniciar sesión con cuatro peces y 60 FPS. Los conejos solo pueden aparecer al añadir peces manualmente. Puedes desactivar el inicio automático desde Aplicaciones de inicio de Windows.

## Onda LAN 1.0
En Windows x64 extrae el ZIP completo y abre OndaLAN.exe. En Android instala el APK. Conecta los dispositivos a la misma red y comparte el enlace de la sala. Guarda los archivos antes de cerrarla.
